### 操作、返回、保存和异常

详细入口、按钮结果、返回目标、状态、校验、持久化和原生依赖见 [逐页契约](./p4-route-contracts.json)。

- 好友会话点麦克风后读权限；授权操作只申请麦克风，需再次按住才录音。松开发送，上滑取消；权限未完成时松手、指针取消/丢失、后台和离页均取消，晚到回调不能发送。真实录音达到上限后进入待发送确认，避免自动发出截断内容。
- 录音先写当前账户、当前对象的暂存草稿；正式消息与附件引用在同一仓储事务中提交。写入失败保留录音和独立文字输入，允许重试或丢弃。消息 commitId 与按钮 busy 防止重复发送；原始录音转存失败保留临时文件供重试，丢弃/离页清理。
- 同一时间只播放一段语音；播放、暂停、拖动位置和进度均来自实际音频。后台、离页、拉黑和退出停止播放。旧夹具在首次播放前没有时长元数据，播放后读取实际时长；不生成假播放进度。
- 浏览器没有模拟原生录音成功，提供真实 PCM WAV 文件导入用于本地闭环检查；格式/大小/长度错误可重新选择，成功发送才形成正式消息。导入与原生录音共享附件授权和事务。
- 视频页属于二级页面，无 TabBar 和残余占位。只允许已确认好友；相机启动、切换、关闭及麦克风本地电平使用设备能力。麦克风默认关闭，只在用户打开时申请；演示不发送网络音视频。样片模式禁用麦克风/切换相机并解释原因，第三个控件明确为样片暂停/继续。
- 挂断保存本地结束原因；结束后可重新开始或按 from 返回会话/Chats。拒绝来电保留原列表。固定测试账号可以手动触发来电演示，不定时伪造别人呼叫。旧活动演示重载后标记中断，不能复活摄像头或假连接。
- 拉黑事务立即终止该关系的演示并阻断附件、语言结果、录音、播放和后续互动；解除不补发。关注、点亮、申请和好友继续使用 P3 的独立实体。
- 文本/语音的语言工具保留原文。语音先选择源语言并转写，再翻译转写文本。转写强制设备端识别，设备/模型不支持即返回 `LANGUAGE_UNAVAILABLE`，不会回退云端。翻译由唯一 Bridge 调用 iOS18+ Translation，系统负责模型下载许可；iOS17可录音/播放但系统翻译返回不可用。同语言结果明确标注原文，无虚构翻译。
- 派生文字按当前账户、对象、原文指纹、源/目标语言存储，只有成功且仍有权限才保存，过期缓存不展示。语言选择/展开状态在同账户本次运行内按对象保留；正文、录音待发草稿在返回/语言切换后保留，重载或退出不承诺恢复未提交草稿。

唯一 Bridge 增量使用 `realtime` service，包含 requestId、Promise、参数验证、取消、超时和结果丢弃。原生耗时文件/仓储/相机会话在各自队列，UI 在主线程。使用 `AVAudioSession` 中断处理、App 后台通知、Web 导航/进程终止清理及页面作用域 ID，避免旧页取消新页资源。

技术预览假设（**不是用户已确认产品规则**）：语音1–60秒、10MiB、单声道AAC原生录音、浏览器PCM WAV导入、上滑72逻辑像素触发取消。前两项由 `domain/realtime.js` 生成原生共用配置，可独立调整。视频仅本机预览/样片，没有远程通话协议和计费。

## 3. 是否影响登录注册流程

不改变登录/注册顺序、固定验证码、18+、原子注册或账号规则。复用当前会话权限；退出时额外释放媒体和语言任务。P1/P2/P3原有 Web 与原生仓储测试继续通过。未扩展 StoreKit、个人中心或设置业务。

## 4. 是否影响本地用户数据

有增量影响：在原仓储增加 `realtime.version=1`、按账户隔离的本地演示记录和派生语言缓存；语音消息引用原有受保护媒体存储。沿用稳定用户/线程/好友 ID，保留两组原始好友、会话和请求夹具。浏览器与原生继续各自使用现有 IndexedDB / Keychain加密 vault，不互相冒充同步。

没有清库、覆盖固定账号或以重置规避兼容。损坏结构返回稳定错误并保留原文件。录音复制、附件提交、语言保存和结束记录失败均覆盖回滚；失败不消费金币/额度。测试只在独立QA origin产生明确的本地消息、评论和演示记录，拉黑检查后已解除；保留已保存样本供复测。

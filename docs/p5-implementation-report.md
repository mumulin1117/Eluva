2. **每个文件解决了什么问题：**
   - `personal.js` / `browser-personal.js` / `PersonalRepository.swift`：资料、主题、反馈、合集更新/引用、帖子删除与账户删除的所有权、校验、原子持久化、提交去重和失败回滚；其他账户数据保持独立。

   - `DraftImagePicker.vue` / `ProfileEditView.vue`：头像更换直接打开既有媒体能力，成功选图后先改草稿；照片添加、主图顺序、移除、错误恢复统一管理。反馈附件不再显示“主头像”语义；合集具有明确 Edit Cover 控件。

   - `browser-repository.js` / `LocalRepository.swift` / `SocialRepository.swift` / `NativeBridge.swift`：沿用认证与资源底座；退出清临时状态，删号立即阻止已删对端互动并取消媒体/翻译。保存资料保留历史社区同意版本。

## 设计依据与仍需签核的差异

[逐页契约](p5-route-contracts.json) 逐一记录设计 ID、更新时间、版本、图层、入口、操作、保存时机、状态、返回和原生依赖；[设计来源](evidence/p5/design-sources.json) 与 [版本复核](evidence/p5/version-verification.json) 保留证据。主要实现前读取 17 张相关稿，另补核 #14/#15 的只读合集依赖，共 19 张。18 张精确 ID 对应的版本为“版本1”；**#32 同名接口错配，版本仍未确认**，不得套用 #14 的版本。

标准稿按 390 逻辑宽核对；设置稿 390×900、资料编辑稿 390×921；195px 目录缩略图不是 CSS 基准。原切图为 4 倍，选择逻辑 2 倍资源。主题稿是 1749×1048 画板。只把背景/装饰作为可裁切视觉，核心布局使用流式容器，没有整页固定缩放。

主要保留：Poppins、Plus Jakarta Sans、Inter、Zen Dots，补入本地 Bakbak One 与 OFL；原始 Mine/菜单/设置/头像框/主题背景素材。主题 Tab SVG 保留原始圆、渐变及字形路径，来源和组合说明在 [asset-sources.json](evidence/p5/asset-sources.json)。字体来源、许可和无法单独内嵌的徽标字体见 [font-sources.json](evidence/p5/font-sources.json)。

本轮浏览器复核修正了：法语 320px 统计断词、确认层的 Poppins 标题及 Jakarta 按钮、合集描述字体、小屏重复扣宽、删号上下按钮层级、主题预览被已存主题覆盖、反馈截图错误套用主图文案、资料头像入口与返回来源。共用资源和状态的改动有相应回归验证。

最终同主题截图还修正了 Mine 默认 TabBar 底色截断背景，以及确认层误用整页背景的问题。确认层沿用项目既有 centered-panel 渐变，主按钮按源29/90采用黑色。帖子纸层角度在标注回退中缺失：原预览白纸下边缘测量约 -5.3°（180点），本轮采用 -5°作为预览重建值，仍须人工图层签核，不冒称原始参数。

保留为明确的预览适配/缺口：

- 编辑输入采用 16px，原稿主要为 15px；这是本轮为聚焦体验采用的技术预览，尚未完成真机缩放验证及正式视觉批准。法语长文、真实 UUID、触控 44pt 和额外业务说明采用自适应换行/滚动。
- 语言、黑名单、关于、协议正文、加载失败、反馈回执等无完整直接稿，使用源白色行、圆角卡片、字体与背景体系补齐并复核；P5 不宣称这些补稿已经获得设计签核。
- 源稿部分复杂渐变/阴影与组件状态无法由标注回退完整导出，复用项目同体系本地资源；确认层、未拆分导出的 camera 线图标及未提供的主题控件状态仍待浏览器逐层/真机视觉签核。没有用整页截图代替可操作 UI。
- 正式自有 EN/FR 协议、申诉及联系方式未提供，页面明确非约束性本地草稿；关于页法语品牌标题为预览译文。最终 Bundle ID、团队签名及 AppIcon 仍待配置。

蓝湖的三个主入口从左到右为「消息 Chats → 首页 Home → 我的 Mine」，默认进入中间的首页。以 Eluva 的三入口定义落实导航，不复制参考原型里的 Discover、Events 等业务名称。P1/P2已按这一顺序落实；P3在同一Chats入口接入正式关系与消息闭环。

一级页面显示 TabBar，各自保存滚动位置和筛选状态。认证、Onboarding、动态详情、发布、资料、会话、好友申请、合集详情、设置和购买都是独立页面或更深层级，不显示 TabBar，也不保留无效底部占位。

弹层保留所属页面的状态；弹层内的取消只撤销本次未保存修改，返回上级时还原原来的滚动位置与输入。

### 2.2 页面树

- 启动：原生 Launch Screen → 原生覆盖层 → 本地 H5 Boot → 按账户状态分流。
- 未登录：Welcome、EULA、年龄确认、社区协议、邮箱注册、邮箱验证、登录、忘记与重置密码、协议正文。
- 注册草稿：连续对话中的邮箱验证 → 姓名 → 年龄／完整生日 → 密码 → 主题 → 性别 → 快速问答 → 简介确认／编辑 → 原子完成。
- 首页：首次引导、发布入口、同频内容、刷新与筛选、使用帮助。
- 动态：未点亮详情、点亮后详情、一次 Reply 联系、媒体查看、作者资料、内容举报。
- 发布：文字和媒体、合集选择、新建合集、受众筛选、可见性、发布结果。
- 消息：全部、关注筛选、未读筛选、点亮记录、帮助、好友列表、收到与已发送申请、会话。
- 会话：文字、表情、图片、语音、录音取消、视频入口、举报和拉黑。
- 我的：当前用户资料、我的点亮、我的帖子、合集、反馈、帮助、设置和购买入口。
- 设置：语言、主题、通知、黑名单、协议、关于、退出和删除账号。

「我的未登录」设计保留为会话失效或受控预览的视觉状态，不自动增加游客访问整套社交功能的流程。

5. 有有效会话且本地账户存在，进入首页；账户不存在或数据损坏则清理失效会话引用并回到登录，不能自动建立账户。

7. 退出登录只结束当前会话并清理媒体与临时任务，不清空账户、帖子、关系、语言或 EULA。

卸载重装重新判断首次安装与系统语言；不能让卸载后仍可能残留的 Keychain 标记直接跳过首次欢迎和 EULA。

首页在数据成功加载后，按当前账户读取权限、可见性、安全规则与筛选条件得到0条同频动态时，显示蓝湖“首页--默认进入”版本1的空态，适用于全部用户；不以新注册或尚未发帖强制进入空态。加载中与首次读取失败显示独立状态，刷新失败保留上次成功结果，不能冒充0条。空态显示实际同频数量和 Share Now；筛选无结果使用同体系文案，并保留轻量恢复筛选入口。首次四步定位引导说明发布、发现、分享入口和导航，仍由 guideDone 记录；首页顶部“？”打开独立的“首页-使用帮助1～4”图文弹窗，与定位引导分离。手动帮助每次从第1页打开，支持左右滑动、分页和键盘切换，Skip 关闭，Got It 前三页前进、末页关闭；不自动播放、不点击遮罩关闭，不读取或改写 guideDone。关闭保留首页内容、筛选和滚动，恢复入口焦点；图片加载失败保留当前说明、分页与关闭能力，并允许重试。引导的退出与完成有明确状态，重复启动不叠加多份遮罩。

### 5.2 点亮与 Reply（2026-10-20 用户纠偏）

详情不显示评论区、评论数量、评论输入或评论发布；旧评论数据兼容保存。未点亮显示 Light Up，点亮后展示头像、姓名、简介、Lit Up 标志、View Profile 和 Reply。点亮与“我点亮的”及通知同步，但不会产生关注或聊天授权。

Reply 是一次私人联系：每对用户跨动态只允许一条待回复信息；成功后灰色按钮可点击说明等待。接收者在消息会话中 Decline 或发送文字回复；回复与连接状态在同一事务保存后才可继续聊天。失败保留草稿，不占用联系机会，重试幂等。已互关或已有 Reply 联系的用户进入正常会话。

详见 [本轮映射与迁移方案](./post-detail-connection-plan.md)。用户内容保持原文；详情不提供语言帮助。内容已删除、被隐藏、私密或拉黑时显示限制与返回入口。

## 6 发布动态与可见性

路径：首页 Share / Share Now → 发布草稿 → 添加文字或媒体 → 可选合集 → 受众筛选 → 可见性 → 提交 → 结果更新 → 返回来源页面。

- 空内容不能提交；纯图、纯视频、纯文字及长度上限尚未正式冻结。P2采用可逆的技术预览实现：正文2000字素、9图或1个60秒/50MiB视频、单图20MiB；详见P2报告，不能当成用户已确认要求。
- 图片、视频经统一 Bridge 获取本地可引用媒体，不把设计稿 URL 作为产品内容地址。
- 保存筛选或弹层设置只更新发布草稿；取消恢复进入弹层前的值，不清空其他输入。
- 新建合集可从选择弹层进入，成功回到原草稿并选中；取消仍回到原草稿。
- 受众筛选（Audience Filters）决定发现与推荐偏好，不授予查看权限。
- 可见性独立保存：Private 为最高优先级；私密时不能出现在他人的发现、个人主页或合集。公开与仅好友的受众选项互斥，发现和主页展示开关仅在可见性允许时有效。
- 2026-10-24：Audience Filters 的四项 Pro 选项按当前账户已验证且有效的会员解锁，保存到原发布草稿，提交时原生与浏览器仓储再次校验；非会员保留锁定表达。筛选决定推荐对象，不改变可见性与原帖访问权限。
- 发布成功后再扣额度、关联合集、更新“我的帖子”和首页；失败不扣次数，不丢草稿。
- 重试使用稳定提交标识，防止同一次发布产生重复帖子。
- 返回存在未提交内容时提供明确的继续编辑与放弃选择；长期保存草稿不是已确认需求，不擅自增加后台上传。

设计显示每日免费 3 条是候选商业规则，正式限额统一配置；不能分散写在多个组件中。

P2当前共用配置`dailyPublicPosts:null`，界面显示不设每日上限；免费2个合集亦不强制执行。配额耗尽、私密和失败不扣减、稳定提交重试不重复扣减已通过仓储测试，正式数值与计日时区仍待确认。

## 7 关系与消息权限

### 7.1 四种概念分开

点亮：对内容表达共鸣。

关注：单向关注与筛选。

好友申请：携带至多一条介绍消息的关系请求。
好友：双方互相关注。另有通过动态 Reply 得到回复建立的联系；两者独立，任一路径有效即可持续私人交流。

单向关注、点亮、会员均不解锁私聊。双方互关可直接解锁，动态 Reply 的接收者实际回复也可解锁。旧好友实体只做一次兼容迁移，不保留第三条授权路径。

### 7.2 好友请求状态

动态陌生人 → 一条 Reply → 待对方回复 → 对方回复并建立联系 → 持续聊天；或双方互关 → 持续聊天。历史好友申请接受会建立互关。

收到请求 → 查看资料与介绍 → 接受或忽略 → 更新好友列表、申请列表与会话权限。

- 同一关系待处理期间禁止重复发请求或再发第二条介绍消息。
- 拒绝后能否再次申请、等待多久和是否消耗额度尚未确认，暂不自动重发。
- 请求失败保留介绍内容与输入形式，重试不产生第二个请求。
- 路由、会话页、发送服务、媒体发送及视频入口都检查有效联系／互关状态，不能只在按钮样式上限制。
- 拉黑优先于任何其他关系状态，所有相关操作立即失效。

P3实际：申请、单向关注、好友、消息、幂等操作分别存储；接收方接受在同一事务中建立唯一好友关系和线程，成功同步P2 Friends可见帖子。忽略后保留终态且不开放第二条介绍；没有自行添加冷却期、重发费用或假自动回复。

### 7.3 消息列表与会话

消息一级页包含 All、Follow 筛选、未读筛选、点亮通知聚合、帮助会话与普通会话，好友入口进入列表及申请。

- Follow 只筛选关注对象，不把这些对象都认定为好友。
- Just Light Up 记录点亮事件；转入普通会话的分类变化与消息权限独立判断。
- “标记点亮消息已读”只更新目标消息；先展示确认，取消保持未读，成功同步徽标。
- 会话输入支持文字、表情、图片和语音；空消息禁用，发送失败可重试，返回保留本次草稿。
- 每条消息有稳定 ID、时间、类型、内容引用、发送与已读状态；未读数量由数据计算。
- 帮助中心显示功能说明及“已记录”反馈结果，不展示本地数据标签，不假装真人客服或云端 AI 已回复。
- 购买成功、点亮和发送消息等事件只影响各自实体，不能通过刷新页面才更新界面。

P3实际：文字、Unicode表情、28个源贴纸、单张图片加可选说明、真实本地语音夹具播放已实现。只在实际接收账户打开会话时写已读，未制造远端回执；帮助为功能说明与已记录反馈，界面不再显示本地数据标签。P4现已增量接入录音和本机视频演示，真机路径待验；旧语言帮助 UI 已按 2026-10-19 用户要求移除。介绍500字素、消息／反馈2000字素和单附件模式是技术预览假设，未作为用户已确认规则。

P3解除拉黑采用保守策略：保留原好友实体与消息，不自动重发申请或补发消息。正式解除后的关系政策仍待确认；该实现不删除历史数据。拉黑继续使用P2同一block实体，对发送、媒体读取、资料和内容权限实时生效。

### 7.4 录音与语音播放

空闲 → 用户按下 → 权限检查 → 录音中 → 移入取消区或继续录音 → 松开后发送／取消 → 恢复空闲。

- 必须处理 pointerdown、pointermove、pointerup、pointercancel、lostpointercapture、App 后台和页面销毁。
- 权限尚未决定时不自动在授权结束后意外发送；需要用户明确的录制操作。
- 太短、设备不支持、录音失败、权限拒绝和发送失败均有可恢复提示。
- 取消录音不生成消息，清理临时音频与计时器。
- 同时只播放一段语音；切换会话、拉黑、退出和进入后台时按统一策略停止。
- 2026-10-19 用户明确移除蓝湖未定义的语言帮助功能：动态、评论及文字／语音消息均不提供翻译、转写、源语言选择和结果面板。既有原文、录音与历史派生数据不删除；界面语言切换仍仅位于个人中心 → 设置 → 语言。
- 录音时长上下限在接入前确认，不能把设计中的 00:01 当固定业务值。

## 8 视频与权限

- 退出：结束会话但保留本地账户资料。
- 删除：明确影响范围并确认，仅处理目标账户及其关联数据；退出与删除是两种不同操作。

### 10.3 StoreKit 与额度

购买路径：入口 → 读取 StoreKit 商品 → 显示真实本地化价格与币种 → 用户确认 → 购买中 → 取消／失败／待处理／成功 → 校验事务 → 更新权益或金币 → 回到原操作。

- 金币为消耗型虚拟物品，不可提现或转让；余额与消费使用统一状态和流水。
- 事务 ID 去重，重复回调不能重复加币；取消和失败不改余额；待处理不提前发权益。
- 恢复能力按商品类型处理，不能承诺恢复已经消耗的金币。
- 模拟购买与 StoreKit 沙盒测试都不能表述为真实扣款。
- 蓝湖“充值”实际上画成 Pro 会员页，同时写按月计费和一次支付不续费；需先确认是自动续订、非续订权益、金币还是组合。不得照图硬编码 $4.99 等价格或续费承诺。
- 候选权益包括头像框、受众筛选、每次推荐数量、发布额度和合集数量；先冻结商品与权益映射，再接入交付。
- 商品配置未提供时可以交付明确的不可购买与重试状态，不能静默模拟付费解锁。

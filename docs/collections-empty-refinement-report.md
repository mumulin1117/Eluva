## 3. 交互和数据影响

- 未改认证、注册、账户接口、原子建号、存储格式或 Native Bridge。
- 帮助为只读说明；打开不创建合集、不改变订阅或帖子；Done／关闭恢复页面与焦点。
- 创建入口仍使用同一 `CollectionEditor` 与提交服务；空名称不可保存，关闭保留本会话草稿，重新打开恢复；保存后进入新合集，返回显示真实列表，连续点击只提交一次。

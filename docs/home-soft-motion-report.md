2. **每个文件解决了什么问题：**
   - 用户明确选择“保留逐条，放慢变柔”。继续每盏灯对应一条实际动态，并将其前插；每条间隔由420ms调整为1000ms，最后收尾1000ms。五条无暂停时约5秒完成，实际读取耗时另计。没有增加固定网络等待，也不改变权限、筛选、批次最多5条及最终业务顺序。
   - 卡片从原340ms、上移14px并缩放，改为800ms仅透明度0.5→1。卡片本身不再位移或缩放，逐条前插引起的列表排列变化继续保留。
   - 灯光改为950ms低亮渐显，移除弹跳与双扩散环；使用原有本地灯泡图标，色相差从每盏54度缩至8度。原图、布局、字体、文案和按钮均沿用。
   - 常态白环从3.6秒放慢到4.8秒；发现彩环从1.35秒放慢到3.2秒，颜色变为低饱和紫、青、粉，线宽从2px减至1.3px，最大扩散比例从1.48减至1.25，峰值透明度从0.95降至0.58。地图水纹与树冠沿用原微动。
   - 第五张卡片淡入完成后保留足够收尾时间，全部灯移除、回到慢速白环。0条、失败、重复点击、迟到结果、筛选与返回仍沿用原状态机。帮助弹层、后台与地图离屏暂停；减少动态效果直接展示真实结果，不逐条等待。
   - 恢复暂停时，既有时钟重新等待完整一拍，CSS从暂停位置续播，因此允许稍长的静止间隔；未声称两者按剩余毫秒完全同步。
   - 速度与亮度为本轮用户确认的实现参数，非蓝湖动画标注。视觉继续复用已冻结的首页版本1及现有资源，没有改用版本2或生成新插画。

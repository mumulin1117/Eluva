## 1 修改文件与目的

逐文件说明见 [source-files.json](evidence/p2/source-files.json)。主要变更：

## 3 业务与交互结果

### 主入口与首页

三 Tab 顺序 Chats、Home、Mine，登录后默认 Home。首页显示实际可读、允许发现的帖子；新账号没有测试帖。固定测试账号的两个示例帖明确标为本地示例，不显示假在线。首次进入按账户打开四步引导，Skip／Done保存完成状态，帮助入口可重播。

刷新只读取实际本地仓储，筛选保存成功后重算列表；无结果可重置。点开详情和返回保留合理纵向／横向滚动、筛选和当前账户状态。刷新失败显示稳定错误与重试；固定测试账号提供明确命名的“一次本地失败”工具，不制造等待。

### 发布、草稿与原子提交

文字、图片或视频可构成有效内容。媒体经唯一 `eluva` Bridge；浏览器使用受控本地文件选择，原生用 PHPicker／相机。没有启动时索取媒体权限。导入期间编辑和重复提交受 busy 限制；错误、取消和不支持设备返回可编辑状态。

合集、受众、可见性使用进入弹层时的工作副本，保存更新草稿，取消恢复原值。新建合集成功后独立保存空容器并选中，取消不创建帖子；合集后续管理留给P5。

返回时可继续编辑、保留并离开、明确放弃。草稿正文与选项只在会话内存中，暂存媒体属于当前账户／草稿。换语言和页面往返保留；关闭或重载整个应用不承诺长期恢复，界面已有说明。没有增加后台上传或把未提交草稿当正式内容。

提交使用稳定 commitId 并绑定操作、目标及规范化 payload。同一提交的重复点击／响应重试返回同一结果；修改 payload 复用已提交 ID 返回 `COMMIT_CONFLICT`。成功后关闭草稿，防止换 ID 再次使用同一个已完成草稿。校验、媒体归属、合集归属、额度、帖子、文件提交标记、合集关联和幂等记录在同一事务中处理。失败回滚；私密与失败不消费公开发布次数。

成功后应用仓储返回的统一快照：首页、详情、我的发布、我的点亮和事件入口立即同步，无需刷新。普通发布回到来源，私密发布回到“我的发布”。

### 权限、点亮与评论

Private优先，实际保存时关闭发现／主页展示。Everyone与Friends互斥，Friends只读取已有确认好友关系。发现偏好不授予阅读权限；未点亮、点亮、关注、好友申请和好友没有混用。P2没有伪造关注、加好友或私聊功能。

每次读取／互动／媒体解析都检查账户、可见性、删除、隐藏及双方拉黑。公开作者摘要只提供姓名、年龄、简介、兴趣等允许展示字段，不泄露邮箱和完整生日。跨账户媒体、合集引用和私密帖子被拒绝。

点亮以 viewerId＋postId 唯一，取消点亮只移除该点亮与对应事件，不删除已有评论。Reply是公开评论；非作者需先点亮，作者可评论自己的内容。评论失败、关闭、返回和换语言保留当前帖子输入，成功后清空，连续重试只保存一条。

举报明确“仅在此设备记录，未发送审核团队”。隐藏／拉黑即时更新，并提供重载后仍可访问的恢复入口。拉黑不改写好友或关注实体。本轮现有演示会话入口过滤被拉黑作者，完整消息服务限制留给P3。

### 媒体与取消

图片实际解码，视频实际读取元数据；原生使用异步 AVURLAsset 验证时长和视频轨道。浏览器不支持相机时明确报 `DEVICE_UNSUPPORTED`，提供选其他来源／系统设置恢复说明，不假装拍摄成功。权限拒绝、受限、缺失、取消、超时和离页结果丢弃沿用统一错误码。

播放器有播放／暂停、进度、重试和查看入口，无自动播放。离开或进入后台停止播放，销毁释放媒体。图库返回保留最后查看的图片索引。沙盒资源校验普通文件与路径，拒绝软链接逃逸；取消草稿不会删掉已成功保存的合集封面。

## 4 规则确认边界

已确认：三 Tab、按账户引导、本地模式、可见性优先、成功后同步、重复去重、失败保留输入、点亮不等于好友、私密／失败不扣额度。

以下是可逆的**技术预览假设，尚未收到用户确认**：正文2000字素、评论1000字素、最多9图或1视频、视频60秒／50MiB、单图20MiB；合集名60／说明300、举报补充500；支持纯文字／纯图／纯视频。长度按字素统计，不以法语重音字符拆分制造限制。

“每日3条”和“免费2个合集”仍是候选商业规则。本轮没有强制这两个数值；共用配置 `dailyPublicPosts:null`，界面明确当前本地预览没有每日上限。测试通过注入限额1验证耗尽、私密和重试边界；没有把测试注入值当用户权益。未来启用每日额度时，当前 UTC 计日假设也需确认。

Pro选项保持锁定，没有接入 StoreKit 或假装付款。原系统翻译、完整社交和完整个人中心不在P2。

## 5 登录、本地数据及适配影响

登录注册核心凭据和顺序未改变；共享弹层、账户切换清理、原生媒体选择和启动首帧就绪有直接依赖修改，原P1自动化已一起回归。启动进入Home时等待其关键本地资源与字体就绪，再通知现有原生覆盖层隐藏。

浏览器继续使用原IndexedDB事务，原生继续Keychain密钥＋加密vault，分别保存各自环境数据。仅在不存在content字段时增加version1内容域；格式异常报`STORAGE_CORRUPT`并保留原数据，不清空账号。原生媒体提交失败清理本次拷贝，正式文件不因失败或退出登录而删除。缓存、滚动和临时草稿按账户隔离；退出清理临时状态，不清正式数据。

六种必测尺寸与EN/FR已覆盖。使用100dvh回退、真实滚动、env Safe Area、visualViewport高度／offsetTop；输入保持编辑选择复制粘贴，普通内容禁止拖拽／选择／长按提取。小于700高时地图控件分列、卡片预览缩小以确保主操作可达；没有整体缩放页面。全部二级路由无TabBar及其占位。

浏览器验证能够确认DOM布局、文字、输入和弹层行为；**P2没有完成模拟器虚拟键盘或真机键盘验证，也没有以浏览器窗口变小冒充真实键盘**。系统Safe Area、权限提示、原生选择器、实际媒体编解码、启动衔接和Xcode运行界面日志仍需解锁设备后补验。

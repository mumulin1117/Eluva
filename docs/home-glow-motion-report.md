2. **每个文件解决了什么问题：**
   - 旧固定百分比灯位较集中且可能叠在头像／分享入口。现在从实际地图区域生成确定性候选，按分散覆盖选点，52×56灯与控件／其他灯保留6px间隙。保护Share、头像实图与数量整行，允许波纹空白区域经过；每批位置固定，避免英法单复数宽度引起抖动。
   - 短屏原200／220px地图无法同时容纳5灯和必要控件，最小地图高度改为300px，使用真实滚动保留卡片操作，不压缩字体、图标或整页。极端不足空间时纯布局函数少返回，不把灯强塞在控件上；本轮规定六尺寸以实际WKWebView结果为准。
   - 灯本体亮度1.35、饱和度1.18、渐亮峰值不透明度1，已亮灯保持0.9；使用已有本地图标，不增加循环闪光或高频亮灭。
   - 每卡独立2000ms融合光，灯与卡共用`--signal-color`。真实卡从飞行开始就计时，装饰副本同步同一颜色、关键帧和当前时间；900ms落地后由真实卡延续约1100ms，下一张插入／旧卡右移不重新计时。光影仅改变阴影，不覆盖图片、文字或按钮点击区域。
   - 逐条时钟1000ms、飞行900ms、右推750ms及业务排序保持；发现idle不截断末卡光效，也不等待光效再解除busy。副本落地立即取消其光动画，真实卡继续；结束恢复原阴影并清理标记。
   - 帮助、后台及离屏暂停；滚动、尺寸变化、筛选、权限／账户变化、刷新、减少动态和离页取消对应装饰。取消后不隐藏真实内容，不新增持久化数据或业务链路。
   - 实施前重新查询蓝湖首页`53ecd7cf-131b-4976-b8c8-52c10658774e`与默认进入`9ceb471c-970d-4817-b764-01eb22189114`，列表更新时间分别2026-10-20T13:43:55.058183Z和09:48:39.189049Z。本轮动效由用户明确要求，静态资源／字体沿用已冻结实现，不混用新版本或将动效参数称为蓝湖标注。

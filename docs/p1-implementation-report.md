# Eluva P1 实施与验证报告

日期：2026-10-17。P1 本地业务闭环已实施并通过下述自动化与运行检查；正式资源签核、签名安装及真机验收尚未完成。此结果不代表产品可直接发布，也不把 P0 中的方案改写为用户确认。

## 范围及文件

仓库起点只有规范与规划，没有可复用应用工程。本轮建立必需的 Vue/UIKit 工程及唯一 Bridge；原始 AGENTS.md、AGENTS_UI.md 和参考 HTML 未改动。

- `package.json`、锁文件、`vite.config.js`、`index.html`：本地构建、启动衔接、CSP 与资源入口。
- `src/App.vue`、`router.js`、`state.js`：首帧确认、路由门槛、会话、内存草稿、单次异步操作、返回和失败状态。
- `src/domain/`、`src/services/`：统一校验、错误、ID、Bridge、浏览器本地仓库、账户隔离与幂等提交。
- `src/components/`：页面壳、按钮、表单、生日、弹层、照片、图标和双语演示音频控件。
- `src/views/`：欢迎、认证、九步引导、条款和最小登录后主入口。主入口只承担 P1 的可验证出口；没有铺设 P2/P3 的静态业务外壳。
- `src/styles.css`、`src/i18n.js`、`src/data/`、`public/`：测量后的视觉、双语字段、独立政策预览、字体和本地资源。
- `ios/Eluva/`、`ios/Eluva.xcodeproj`：UIKit、WKWebView、原生仓库、Keychain、媒体/权限、资源处理、启动和本地化。`Simulator.entitlements` 只用于模拟器本地签名。
- `scripts/`：准备选择项、生产资源审计、同步和可重建 Xcode 工程。
- `tests/`、`ios/EluvaTests/`：业务、Bridge、UI 状态、双语及原生持久化回归。
- 本报告、`p1-route-contracts.json`、`evidence/p1/` 与实施计划状态：交付契约及证据。文件清单另见 `evidence/p1/source-files.json`。

## 操作、返回与保存

- 启动：先决策en/fr，再读取本地会话；无会话到Welcome，有有效账户到Home。损坏仓库显示保留数据的错误，不清库。首装依据应用沙盒和安装UUID，Keychain残留不能跳过首次流程。
- Welcome/EULA：拒绝返回未勾选欢迎；同意写独立偏好并勾选欢迎；欢迎撤回勾选也更新持久化。条款/隐私可进入正文，返回恢复原弹层或页面。未同意不能进入认证。
- Age：生日面板的取消不修改原值，保存写内存；按完整生日判断18+。不合法、未来和未满18岁均不能进入社区。返回欢迎先确认保留编辑或放弃草稿。
- Community：独立勾选后继续；条款正文返回保留勾选；上一步到Age。它不是邮箱验证或真实学生身份认证。
- Sign Up：邮箱、密码、确认密码分开；校验邮箱、8位含数字、两次一致及账户不存在。通过只创建内存认证上下文。修改邮箱或密码撤销UI旧验证授权，防止浏览器前进绕过重新验证；上一步到Community，切登录前确认放弃。
- Verify Email/Code/Success：邮箱承接注册值，可修改；开始本地验证进入单一真实输入承接的六格。错误保留当前输入与`INVALID_VERIFICATION_CODE`；重复获取仍为567567，不造假邮件或无意义40秒等待。Code返回Email，Success返回Email或继续Basic。
- Log In：邮箱不存在为`ACCOUNT_NOT_FOUND`，密码错误为`WRONG_PASSWORD`；不创建账户。成功才持久化会话并到Home。返回Welcome，密码成功后清出输入内存。
- Forgot Password：Email→Code→New Password→Log In。邮箱修改撤销原UI上下文；注册与重置授权按用途隔离。新密码写入成功才消耗授权并清空密码输入，失败保留字段及授权供重试。返回依次到Code、Email、Log In；离开Email取消旧重置上下文。固定测试账号保留固定密码并说明使用新本地账号测试重置，这仍是保护测试夹具的保守实现选择。
- Basic：显示名与生日校验；性别默认不透露，代词可选。University/年级、Major和Connection Goal保留独立页并可跳过，不添加学生域名白名单或必填门槛；这些可选性沿用P0的保守方案，未冒充用户签核。
- Photos：主动选择来源才调用原生相册/相机；取消不改变已导入照片，拒绝/受限/不支持可选其他来源或去设置。成功照片仅在暂存区；两张才可继续；可删除、调整主图。图片最大20MB属于本地资源保护边界。相册使用PHPicker，不在启动时申请整库权限。
- About：可跳过；300字按字素校验，超限提示且保留输入。Interests：至少3个稳定ID。Icebreakers：恰好3个不同问题，第四项提示先取消已有选择；不要求回答或录音。Notifications：可拒绝/跳过，真实返回系统状态，不发送远程推送。
- 九步普通返回保留草稿、选项和对应滚动位置。Complete可回各资料步骤修改后回摘要；提交过程中禁止重复提交和返回。结束成功才创建账户与会话；退出仅结束会话，不删除账户或照片。资料只展示年龄，生日仅本地私有。
- 全部认证、九步、摘要和正文无TabBar及占位；只有最小Chats/Home/Mine一级入口显示TabBar。测试线程明确标“本地演示”，独立关系/申请/消息字段不混作点亮或关注。

## 原子性与本地数据

浏览器：账户、凭据哈希、媒体归属、commitId和会话在同一个IndexedDB读写事务提交。iOS：先完整复制暂存图片，再原子替换包含账户、凭据哈希、commitId和会话的AES-GCM加密vault，成功后公布内存快照；失败回滚新复制文件，保留草稿重试。崩溃留下的无引用文件在下次安全清理，不清除已引用账户媒体。

凭据使用独立盐的PBKDF2-SHA256，原生vault密钥在Keychain。注册草稿不持久化密码、生日和用户资料；图片暂存不等于正式账户。commitId绑定flowId，重复/并发提交只生成一个账户。固定测试ID不被其他注册覆盖，其他账号不获得测试会话和媒体。

Bridge只有一个`eluva`入口；检查主框架、来源、版本、requestId、参数结构与大小，Promise统一超时/取消，销毁和迟到结果丢弃。媒体请求有独立操作代次，避免旧选择器回调串入新请求；耗时解码和相机编码不占主线程。

本地资源校验URL解码、MIME、资源存在、缓存及路径边界，拒绝路径穿越和软链接逃逸；用户媒体另做当前账户授权。静态bundle资源使用WebKit所需的CORS头，用户媒体不开放该头。参考：[WKURLSchemeHandler](https://developer.apple.com/documentation/webkit/wkurlschemehandler)、[WebKit自定义协议跨源支持](https://bugs.webkit.org/show_bug.cgi?id=205198)。

### 1.1 历史已确认规则（适用性以顶部更新为准）

- **C01**：邮箱+密码分离登录注册；顺序按正式链路；无 Apple/手机号/登录自动建号；验证码固定567567。 来源：AGENTS.md §§6.2–6.4。
- **C02**：注册仅内存草稿，完整 Onboarding 后落正式账户；en/fr；稳定ID；完全本地模式。 来源：AGENTS.md §§6.3,7,8。
- **C03**：EULA 与 Welcome 勾选双向同步；普通文本图片禁提取，输入保留编辑；六种视口、Safe Area、键盘与失败闭环。 来源：AGENTS.md §§6.2,9–11。
- **C04（已被 2026-10-19 新要求替代）**：历史方向为认证使用明确表单、九步资料引导延续聊天式视觉。原来源：用户当时回复采用混合方案；当前改为蓝湖连续对话、资料顺序与快速问答。
- **C05**：密码至少8位且含数字；照片至少2张；兴趣至少3项；破冰问题选3项；简介可跳过且最多300字。 来源：用户本轮明确回复：采用整组规则。
- **C06**：注册必须年满18岁，按完整生日计算；生日只本地保存、不公开，资料只显示年龄。 来源：用户本轮明确回复：采用18+与上述可见性。

密码规则只要求“至少 8 位且含数字”，不附加未确认的必须含大写、小写或特殊字符条件。照片数量指成功导入的有效照片；破冰规则指选择三个问题，不等于必须回答三个问题或必须录音。

### 1.2 具体实现方案与待冻结项

以下内容保持“方案”或“待确认”，不加入上面的确认清单。已获本轮确认的年龄规则不再列为待定。

- **P03 方案**：验证码页使用单一真实输入承接六格视觉，按钮显式验证；重发40秒冷却沿用蓝湖候选，仅节流，不使567567过期。返回改邮箱使旧验证上下文失效。 影响：冷却秒数可配置，不影响固定码规则。
- **P04 方案**：退出注册使用保留当前进程草稿的确认弹层；明确放弃才清理临时数据，杀进程后不恢复半成品账户。Complete 返回 Notifications，资料摘要可跳回对应步骤并回到摘要。 影响：补齐返回与取消体验；不增加注册步骤。
- **P05 方案**：固定测试账号不允许改密或删除，提示使用本地新建账号测试该路径；避免违背固定凭据要求。其他账号正常本地重置。 影响：需在忘记密码接入前决定测试账号例外文案。

本轮提出的三个关键问题均已得到答复：混合视觉方向、关键字段门槛、18+及生日隐私。学校/年级/专业/连接意向的必填性、可选资料的公开范围、固定测试账号改密例外仍需在对应页面实施前冻结；当前方案不擅自增加门槛。本轮不冻结商业权益、聊天扩展、主题和十题测评。

## 2 P0 当时的链路与导航（历史记录，新实施按当前重构计划）

启动：S01 系统 Launch Screen → S02 原生覆盖层 / H5 Boot → 按本地会话分流。无会话进入 A01；有效会话进入蓝湖主入口。主入口在本阶段以 `MAIN_ENTRY` 表示，不把旧计划的默认 Tab 推断冒充已确认新规则。

注册：A01 Welcome → A02 EULA（首次或未同意）→ A03 Age Confirmation → A04 Community Agreement → A05 Sign Up → A06 Enter Email → A07 Code → A08 Success → O01 Basic Info → O02 University → O03 Major → O04 Photos → O05 About → O06 Interests → O07 Connection Goal → O08 Icebreakers → O09 Notifications → O10 Complete → MAIN_ENTRY。

登录：A01 → A09 Log In → 校验成功 → MAIN_ENTRY。创建账户入口进入年龄/社区流程，不能跳过前置同意。

忘记密码：A09 → A10 Email → A11 Code → A12 New Password → A09。注册验证和重置验证各自绑定用途与目标，不能互相授权。

九步资料进度统一显示 1/9 至 9/9；Complete 是审阅和提交单元，不是额外的第十个资料字段步骤。身份、兴趣和意向选项在各自步骤内完成，旧主题与十题测评不追加为强制路径。

所有本阶段 H5 页面均无 TabBar，也不保留其底部空位。普通上一步保留当前进程草稿；明确离开注册才使用 X02。正文从哪里打开就回哪里，EULA 弹层和勾选不丢失。

### 3.3 已定位的冲突

- 蓝湖同名“登录注册进入1”有两个不同imageId：#34是EULA，#52是Welcome，不能按名字合并。
- 浏览器 iOS 标注为390×844pt；清单195×422仅预览。#43生日面板所在画板更高，不统一假定所有稿844。
- 认证与九步资料的正式新流程没有成套直接蓝湖稿，主规范/参考原型定顺序，蓝湖定可复用视觉。新补稿没有蓝湖设计ID和版本，必须保留null而非借用旧ID伪装新稿。
- 字体不是全局一种：EULA标题/按钮为Plus Jakarta Sans，正文与引导为Poppins。字体文件与授权未在仓库发现。
- 旧性别等稿将明文密码当聊天回应，正式流程必须移除；密码只在当前受保护输入控件内显隐。

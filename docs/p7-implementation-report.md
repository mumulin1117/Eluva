- **错误上下文串页：** 不支持相机的错误曾遗留到合集/帖子/删号确认。打开相应确认前清除无关错误；复测相同操作链后确认文案干净，取消保留资料；没有未经确认提交永久删除。

- **重启样片控制状态失真：** 重新开始重置暂停、相机、麦克风、计时和电平；播放/暂停跟随真实video事件，异步播放有busy和失败恢复。暂停→结束→再开始后实际video为`paused=false`、`readyState=4`，不再残留暂停提示。录制样片是明确标记的1秒本地循环，不是真实远端视频。

- **无人接听的演示来电占用：** 横幅按创建时间30秒自然到期，经既有Bridge原子结束；接受后清理横幅计时器，失败可重试，离页丢弃迟到结果。浏览器实际等待31秒后横幅消失，重新查看同一callId仍显示“未接受前已过期”；Web和原生验证失败回滚、重试释放及迟到leave不覆盖原因。**30秒是可逆技术预览默认值，未当成用户确认的产品规则。**
- **资源检查及历史证据：** 构建检查对枚举路径做精确大小写/编码/越界校验；构建证据目录可指定，日常默认`.build/evidence`，避免覆盖P6历史。没有用重置用户数据或刷新来解决同步问题。

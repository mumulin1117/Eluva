   - `src/home-discovery-motion.css`：放大灯泡、900ms落卡、750ms右推及减少动态保护。

2. **每个文件解决了什么问题：**
   - 原卡片逐条前插只有淡入，旧卡直接跳到右侧。现在使用稳定ID的真实列表布局，旧卡750ms平滑右移，延后140ms与点灯衔接。
   - 灯容器从32×32放大至52×56，原始图标从23×29放大至38×46；保留原比例、柔和光晕及本地素材，不增加频闪。
   - 每次成功读取后，逐条时钟仍1000ms；先点亮对应灯，真实卡片的装饰副本从灯中心以900ms落入首卡位置，结束移除副本并显示原卡。最多5条，最后收尾1000ms，最终保留既有业务排序，不增加固定网络等待。
   - 飞行副本复用PostCard与相同遮罩，置于主内容可视区域的装饰层，`inert`、`aria-hidden`及`pointer-events:none`避免重复朗读／点击；不另建动态数据或业务链路。
   - 刷新复用旧卡ID时，落点取列表真实首槽，不能取旧卡FLIP过渡中的视觉坐标。窗口尺寸或主滚动位置改变时移除过期装饰，真实卡继续可见；不强制滚屏追随动画。
   - 旧批次离场立即完成，不让TransitionGroup继续保留已离开的卡片占据首位；右推只用于本轮逐条加入的卡片。
   - 帮助弹窗、后台及离屏暂停视觉；离页清理。减少动态效果直接显示真实结果，不逐条飞行或右推。失败、重复点击、0条、筛选、返回及账户权限保持原规则。
   - 实施前重新查询蓝湖首页`53ecd7cf-131b-4976-b8c8-52c10658774e`（列表更新时间2026-10-20T13:43:55.058183Z）及默认进入`9ceb471c-970d-4817-b764-01eb22189114`。接口本次首页解析为Sketch标注fallback，未提供可验证版本号；不据此切换版本或替换静态资源。沿用已冻结版本1地图与现有卡片遮罩，动效尺寸／速度为本轮实现参数，不称为蓝湖动画规格。

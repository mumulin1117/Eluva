2. **每个文件解决了什么问题：**
   - HomeView / 专属 CSS：常态三道白环持续向外扩散，周期3.6秒；首次读取和主动刷新变为紫／青／粉彩环，周期1.35秒、范围与线宽增大。读取期间沿用实际 busy；已有卡片保留，不点虚假灯。
   - 真实读取成功后，最多5条有效结果，每420ms点亮一盏原始灯泡图标，同时将对应卡片加到列表最前。最后一条入场后再留420ms完成入场，全部灯消失、恢复白环慢速；5条无暂停时约2.1秒。不以计时器假装网络请求，业务数据在实际读取完成时已更新。
   - 灯按批次从后向前呈现，因此每次前插且最终保留既有推荐顺序；最后亮的灯对应列表最前一条。未改变循环分组、最多5条、权限、安全规则或新发布优先。返回保留完成后的顺序、筛选及合理滚动，不重播发现序列。
   - 空结果不点灯，成功读取后显示原空态；首次失败使用可重试状态，不显示0匹配。刷新失败恢复原卡片顺序及横向位置。业务缓存已有内容而首次首页读取失败时，继续显示缓存。动画中可见批次变化会立即结束旧序列并与新批次对齐。
   - 卡片使用自身的轻微上移／淡入，不保留旧卡片退场DOM，避免刷新时新旧卡片短暂叠成6条以上。只有刷新入口在呈现期间防重复；已有帮助、发布、查看卡片等入口保留现有业务行为。
